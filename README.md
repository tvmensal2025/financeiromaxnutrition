# Sistema Helena

Aplicação do fundador ligada ao Supabase `wxkgrykduqtsgmjkzlou`.

A Helena classifica a fala, grava na tabela do assunto e mantém uma única frente em execução. Caixa e DRE saem dos lançamentos. Ausência de lançamento não vira saldo zero.

## Uso local

```sh
npm install
npm run dev
```

O endereço local é `http://localhost:8080`. As chaves ficam em `.env.local` e não entram no git. A chave de serviço não fica no navegador.

```sh
npm test
```
